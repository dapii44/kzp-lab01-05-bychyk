# kzp-lab01-bychyk — звіт про спортивні тренування

Консольна Java-програма з курсу «Кросплатформні засоби програмування»
(Національний університет «Львівська політехніка», КІ-304, Бичик Вадім, **варіант 2 —
«Спортивні тренування»**).

## Призначення

Програма читає записи про тренування з `data/input.csv`, перевіряє їх, обчислює чотири показники
та формує звіт у консоль і текстовий файл. Хибні рядки не зупиняють програму: для кожного
пропущеного рядка у звіті вказано номер і причину.

## Формат входу

UTF-8, один запис у рядку, поля розділено крапкою з комою, десяткові числа — з крапкою:

```text
дата;вид;хвилини;дистанція_км;калорії
2026-09-01;Біг;45;7.50;520
```

| Поле | Тип | Правило |
| --- | --- | --- |
| `date` | String | не порожнє, формат `YYYY-MM-DD` (розбір дати не вимагається) |
| `kind` | String | не порожнє |
| `minutes` | int | ціле, `>= 0` |
| `distanceKm` | double | скінченне, `>= 0` |
| `calories` | int | ціле, `>= 0` |

Коментарів у CSV немає: кожен непорожній рядок є даними.

## Показники (варіант 2)

1. кількість коректних записів;
2. сумарний час (хв);
3. сумарна дистанція (км);
4. найбільша витрата калорій.

## Збірка та запуск

```text
./mvnw verify          # macOS / Ubuntu: компіляція, тести, JAR, SpotBugs
mvnw.cmd verify        # Windows
java -jar target/lab01-1.0.0.jar --version
java -jar target/lab01-1.0.0.jar
java -jar target/lab01-1.0.0.jar --input data/input.csv --output out/report.txt
```

Параметри: `--help`, `--version` (версія з номером збірки, наприклад `1.0.0+local` локально
і `1.0.0+42` у CI), `--input <файл>`, `--output <файл>`.

Коди завершення: `0` — успіх; `1` — у файлі немає жодного коректного запису; `2` — хибні
аргументи або помилка читання/запису файла.
